# 性能衔接配置（2026-11-16，性能计算前登记）

本文件冻结接口预检与后续性能对照口径；大批性能任务在结构验收及预检完成后执行。

- 输入为本轮结构中严格身份/几何通过且fine阶段收敛的唯一候选；四组共享身份只算一次。保留所有原始生成、选样、组装、结构和性能失败分母。
- 连接体仅羧酸中和后的分子形式净电荷须为0；额外离子基团的补偿机制本轮未建模，相关候选标记charge_compensation_unmodeled并保留失败，不通过PACMOF总电荷归零掩盖形式电荷问题。
- PACMOF原有模型分配电荷；核验原子数/元素/晶胞和位点对应、有限数值、总电荷绝对值≤1e-3 e。所有输入与输出哈希保留，失败不补零。记录算法自带的电荷归一化行为。
- 沿用widom_sih4/ff和molecules的实际定义并冻结文件哈希：框架UFF、CO₂三点带电模型、SiH₄现有单点模型，Ewald精度1e-6、截断12.8 Å、298 K、刚性框架。该力场定义为本项目计算模型；结果不直接当实验值。
- 超胞按晶胞垂直高度（体积/对面面积）而非仅边长确定，每方向ceil(25.6 Å/高度)，保证最小垂直盒宽覆盖两倍截断。
- Henry：SiH₄及CO₂两组分各零初始分子WidomProbability=1，5000cycles，种子1701/1702。报告两物种Henry系数及S_CO2=K_CO2/K_SiH4，同时保留SiH₄亲和性。
- 混合GCMC：1 bar，CO₂摩尔分数0.001、SiH₄0.999；30000生产cycles+5000初始化，种子1701/1702。报告绝对吸附量及S_CO2=(q_CO2/q_SiH4)/(0.001/0.999)，项目指标方向为去除CO₂。零/低采样量、误差与未完成明确单列。
- 不按Henry结果挑选GCMC样本；全部满足接口要求的抽样结构运行，跨组同身份复用。若资源或接口阻断，先报告实际覆盖，不能把未执行任务标成性能失败或已完成。
- 先以既有已审计精修B01作为独立接口控制，PACMOF+100cycle Widom/GCMC仅确认能运行，不纳入条件性能组统计。预检不采用其数值筛选新候选。
- 原条件标签CO₂工作容量的精确单位/工况尚待数据来源核查；本轮项目Henry/GCMC指标与原标签分开解释。
