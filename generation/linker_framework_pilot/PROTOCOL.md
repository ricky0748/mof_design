# 连接体—框架组合小试 · 预登记 v1

登记日期：2026-11-13。冻结文件、输入清单与SHA256由`prepare.py`写入服务器试验目录；冻结发生在模板组装和新弛豫前。

## 问题与干预

同一个化学合格的MOFFlow-2连接体，在原生生成框架和兼容模板构建框架下，能否得到保留连接体身份的有效结构？

- A：该连接体在千样本批次中的原生CIF，使用最小原始序列索引作为唯一代表。
- B：同一连接体，羧酸锚点识别、ETKDG(seed=7)、PORMAKE组装，固定pcu拓扑+N16(Zn4O)节点。
- 模板组合必须在EGMOF既有千样本中至少有一个结构有效的实际记录，并保存该记录、源CIF及哈希。B调用现有组装器，未重新调用EGMOF生成模型。
- 连接体是配对固定因素。节点、拓扑、化学计量和构建方式可以改变，因此结论对应“框架构建方案整体干预”；原节点元素与新节点元素逐样本登记。

## 样本选择

1. 已有MOFFlow-2千样本中，序列化学过滤通过，有原生CIF和可追溯序列索引。
2. 只有一种唯一含碳非金属分子片段，允许同一连接体重复出现；不拆混配体框架。
3. 规范化后恰有两个羧酸/羧酸根锚点，无其他主要锚点；最多60个重原子。羧酸根质子化用于构筑块生成，重原子连接图必须保持一致。
4. 按唯一原始canonical SMILES去重，最小seq_idx为代表。优先取训练序列集合差中的新片段，上限12个，其余用训练中已有片段补齐到20个。
5. 同一新颖性层内按SHA256(`20261113|canonical_smiles`)排序。所有入排原因、候选池和样本清单保存。选择不读取原生结构成功标签或MOFid结果。

“训练外”沿用现有canonical SMILES差集定义；本试验不把它升级为新骨架声明。

## 兼容性与计算预算

- 固定一个主模板，B每个连接体一次组装尝试。不会在看到结果后更换连接体、模板或构象种子。
- 与现有锚点判据一致：二齿连接方向相对X–X轴的最大偏差≤20°。不兼容/嵌入失败计入B的原始20个分母，不补样。
- 原生A和可组装B都从原始CIF开始，统一MACE-MP medium、float64、晶胞可变、BFGS、150步、fmax=0.2、maxstep=0.05。
- 每结构外部超时600秒，最多1000原子；超限、超时与工具错误标记unresolved，分母保留。最多8个并发、每GPU最多1个试验任务、CPU线程限制2。
- 两个阳性控制：BDC、BPDC在pcu/N16中经同一锚点和组装流程；控制失败时先诊断流程，不修改已选样本。
- 正式最大20个A+20个B+2个阳性控制。B兼容性失败不消耗弛豫配额。控制预检及故障复核的实际次数另记。

## 验收与分析

共同几何标准：原子数保持、dmin≥0.9Å、ASE共价半径×1.15连通片段数=1、体积比0.75–1.25。报告150步预算内结果，同时单列优化收敛标志。

MOFid在相同版本下处理两臂弛豫后结构（可读取时），保存完整身份、拓扑、连接体与解析失败。连接体匹配对两侧统一做羧酸O的电荷/质子化标准化；保留原SMILES、匹配键和重原子图检查。拓扑未知、未恢复目标连接体和计算失败分别记录。

- 主终点：20个配对单位中，几何有效且目标连接体被MOFid恢复且拓扑完整识别的比例。
- 次终点：组装率、几何有效率、目标连接体恢复率、完整拓扑率、优化收敛、每次尝试耗时。
- 配对结果：A/B都成功、仅A成功、仅B成功、都未成功；报告原始20个分母以及双方可评估子集，不把unresolved写成结构缺陷。
- 按训练内/训练外、原生节点元素和兼容性分层。新颖性与重复结构分别统计。
- 现有原生UFF/MACE历史结果只作附表；本次两臂的统一新MACE计算用于直接比较。EGMOF659/1000只作背景，未加入本次可归因配对终点。

范围：这是小样本、回顾性来源的机制试验，评价固定连接体在指定模板构建下的可用性。后续如有增益，再以独立生成批次验证。
