# 组合路线同预算确认：阶段终结协议

2026-11-13，生成前登记。完成本协议内的计算、审计、质量—成本选择和适用边界总结后结束结构生成确认阶段，不继续逐例修复。

## 固定样本与生成

MOFFlow-2原条件模型，target5.0、temperature1.0、序列种子1301、batch50，最多且固定生成600条。输出与检查点配置链接隔离于新目录。原生坐标预测同用种子1301；为24GB GPU固定max_batch_size8、num_workers4，其余模型配置不变。

沿用序列化学过滤，单有机连接体类型、≤60重原子、恰两个羧酸锚点。归一化身份排除既有20+20+18=58种连接体。按SHA256(budget1301|ligand_key)排序取最多30种，代表为每种最小序列索引；不足30使用实际n，不补采样。选样在结构预测和训练标签比较前冻结；所有失败保留分母。

## 三种生产策略

- A：原生预测CIF，MACE上限300步/1200秒。
- S：固定pcu/N16，单构象固定种子7，MACE上限300步/1200秒。
- D：相同模板，构象固定7和19，各上限150步/600秒；两个分支全部执行，预算合计300步/1200秒。候选终点为至少一个分支通过，另报两分支都通过。

MACE medium float64、变胞BFGS、fmax0.2、maxstep0.05、1000原子上限、skin0，8张3090每卡单任务、CPU线程2。不使用失败的几何预处理、不改模板、不增加种子、不放宽阈值。最多120个正式逻辑分支，加2个BDC控制。

为减少重复，先运行A300/S300/D19_150。S若在≤150步且任务墙钟≤600秒内收敛（无论最终结构验收是否通过），其相同输入、模型、阈值与优化路径的终态可直接作为D7分支；单独保存逻辑预算签名、父记录哈希和输出校验。否则D7独立执行150步。D的逻辑成本仍完整计入共享S终态耗时，物理执行成本另列；不把S的>150步收益计入D。

## 严格终点与审计

最终CIF复读：原子数保持、最短距离≥0.9 Å、单连通、体积比0.75–1.25；官方MOFid获得完整身份且连接体类型集合与目标完全一致。S/D还须预期pcu，A允许其原生完整拓扑。收敛与终点分开。类型集合核验不替代计量数与热力学稳定性证明。

原子数同时核对P1原始CIF显式位点数、ASE读入与最终输出；读入时合并重叠位点不计为原子数保持。

冻结模型、协议、脚本、来源和输入；签名缺失/不一致拒绝复用。gt_data_batch.data_idx映射原生输出。身份识别重复输出按字节SHA256共享；所有失败/超时保留原分母。训练内外标签在选样后计算；同时报告原canonical与仅羧酸根中和两口径、参考覆盖缺口。

报告每策略成功率、配对得失、双种子一致性、批内身份重复、训练身份命中、元素/大小/角度连续范围、GPU任务墙钟、设置/优化耗时、原子步数及每有效框架成本。实测任务墙钟包含进程和模型加载，非GPU核函数时间。原生坐标预测耗时额外报告；步骤同上限不假定实际成本相同。描述性Wilson95%区间及配对bootstrap成本区间（2000次，种子1302），不按p值选路线。

## 预登记路线选择

先按S与D比较，采用固定20%成本差作为实际取舍阈值：

1. D成功数更高，且每有效框架任务墙钟成本≤S的1.2倍，推荐D；S零成功而D有成功也推荐D。
2. 成功数相同，默认更简单的S；只有D成本≤S的0.8倍时改推荐D。
3. D成功数更低，或增益的成本超过上述阈值，默认S，单列D的质量/成本取舍。
4. S和D都零成功，则不确认固定模板路线。原生A若在成功数不低于推荐组合策略、且成本不高时，再检查加上原生坐标预测成本后是否仍占优；占优则推荐A，否则报告Pareto取舍。

该选择为本批和本实现预算下的阶段建议；小样本、固定目标、二羧酸连接体及固定pcu/Zn4O范围保留。结束时明确可用接口、失败边界与后续条件响应/吸附评价入口，DAO-P继续备选。
