# 结构生成确认阶段：结项报告

状态：本阶段已结束。推荐默认方案：**单构象种子7、300步**。

双构象有质量收益，但成本增幅超过预登记20%，默认单构象并保留取舍。该建议按计算前登记规则形成，范围限于本批与当前实现。

## 预算与成本解释

正式物理任务92次；D7早收敛复用28条。D的逻辑成本仍计入该分支完整耗时，物理执行成本单列，避免缓存使D显得更便宜。所有控制、失败、超时与未收敛记录保留。

任务墙钟包含模型/进程加载和退出，反映当前单进程单任务实现，不是GPU核函数时间。原生坐标预测成本另列；模型长期驻留或改批处理会改变成本，需要另行验证。名义步数同上限不代表实际成本相等。

## 严格验收与不确定性

最终CIF显式原子数保持、距离、连通性、体积；MOFid完整身份、目标连接体类型集合一致；S/D预期pcu。收敛另列，类型集合不提供计量数/分解稳定性证明。比例区间与配对成本bootstrap见summary.json，点估计选择不替代广泛泛化证据。

## 实现偏差记录

原生预测实际使用官方入口的20条/批，而非计划8条/批；配置项层级未被预测入口读取，worker=4生效。该偏差在CIF转换和MACE前记录，没有按结构结果重启或换样，保留了真实有效配置与成本。工作代码已修正未来批大小键路径，原冻结代码保留在results。MACE预算和验收规则未变。

## 可复用交付与阶段出口

deliverables/cifs包含推荐策略的26个验收通过CIF，manifest.json记录选用分支、收敛、输出哈希和训练标签。D代表选择先取收敛的通过分支，再按种子7优先；这项交付排序不改变成功数或成本。

可复用批次接口：selected/targets/build JSON → 签名保护的run.py → manifest → 官方MOFid → 严格身份检查与报告。尚未封装自然语言产品入口。

后续入口：在已冻结生产策略上登记目标条件响应与吸附性能对照；复用已有孔道、电荷、Widom/GCMC管线。DAO-P继续备选。本阶段到此结项，不再逐例修复。

审计见results/AUDIT.json；完整数据见results/pairs.csv、summary.json及results_bundle.tar.gz。

## 电荷兼容性边界补充

B29原始SMILES形式电荷为−6，仅中和两个羧酸根后仍为−4，含额外带负电的含硫氧基团；本批其余29种在该归一化后净形式电荷为0。当前固定模板只按二羧酸连接构建，额外阴离子基团的配位与电荷补偿未专门建模，B29在两构象下均未通过连接体类型保持。该结果作为接口适用边界，未事后剔除B29或改变26/30、28/30统计；形式电荷来自SMILES，不是对最终CIF电子态的计算。逐样本数据见results/charge_scope.json。
