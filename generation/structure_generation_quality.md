# 生成结构质量评估（三引擎，统一口径）

更新：2026-11-11。本轮把 SiH₄/CO₂ 性能评价拿开，专注**结构生成本身**：生成器能否产出合法、唯一、可弛豫、多样的结构。

## 1. 数据与口径

三引擎各 100 个无条件生成样本（同一批次，单种子）：

| 引擎 | 生成方式 | 可组装 CIF |
|---|---|---|
| MOFDiff | 无条件（BW-DB 预训练） | 79/100 |
| MOFFlow-2 | 目标条件（CO₂ working capacity） | 77/100 |
| EGMOF | 目标条件（CO₂ 2.5 bar 吸附量） | 89/100 |

指标定义：

- **原始几何干净**：所有原子间距 ≥0.9 Å，且共价连通片段数为 1（ASE 共价半径 ×1.15，PBC）。
- **断开片段**：连通片段数 >1（游离配体/分子）。
- **去重唯一**：pymatgen StructureMatcher（ltol 0.3、stol 0.5、angle 10），同化学式且体积比 0.5–2 的才比较。
- **UFF 可参数化**：lammps-interface 生成输入 + LAMMPS 读取成功。
- **UFF 有效**：UFF 弛豫后 dmin ≥0.9 Å、单片段、原胞原子数与输入一致、体积变化在 0.75–1.25。
- 数据库：`generation/structure_quality/*.csv`（precheck、dedup、uff_summary）。

## 2. 结果

| 指标 | MOFDiff | MOFFlow-2 | EGMOF |
|---|---|---|---|
| 可组装 CIF | 79/100 | 77/100 | 89/100 |
| 原始几何干净 | **26/79（32.9%）** | **40/77（51.9%）** | **36/89（40.4%）** |
| 有 <0.9 Å 重叠 | 37（46.8%） | 37（48.1%） | 52（58.4%） |
| 含断开片段 | 22（27.8%） | 12（15.6%） | 4（4.5%） |
| 去重后唯一 | 79/79（100%） | 69/77（89.6%，8 个重复） | 89/89（100%） |
| UFF 可参数化 | 77/79 | 26/77 | 89/89 |
| UFF 弛豫后有效 | 41/79 | 25/77 | 80/89 |
| UFF 工具失败 | 2 | 51 | 0 |
| 工具失败中 MACE 有效 | 0/2 | **26/51** | — |
| **最终有效（UFF ∪ MACE）** | **41/79（51.9%）** | **51/77（66.2%）** | **80/89（89.9%）** |
| 唯一化学式 | 79（100%） | 54（70%） | 88（99%） |
| 金属分布 | Zn 57 / Cu 18 / V 2 / Cr 1 / Ba 1 | V 39 / Cu 30 / Zn 6 / Ni 1 / Cr 1 | Zn 59 / Cu 16 / Cd 5 / Zr 3 / Co 2 |
| 晶胞体积范围（Å³） | 1168–15,939 | 923–4,444 | 980–47,987 |

**工具失败分离（2026-11-11）**：MOFFlow-2 的 51 个 UFF 失败主要是 lammps-interface/LAMMPS 的工具 bug（42 个 `Invalid atom ID in Dihedrals`、8 个游离分子导致的交互 EOF、1 个无输出）。尝试了 CIF 坐标 wrap 重写和给 lammps-interface 传入多个确认，均不能修复 dihedral 错误；改用 MACE-MP fallback 弛豫（150 步、fmax 0.2、每卡 1 个任务、限制 OMP 线程）。结果：

- 51 个工具失败结构中 **26 个经 MACE 弛豫后有效**（体积比 0.948–1.034，dmin≥0.9、单片段）；
- 其余 25 个仍有 >1 个片段或原子重叠，属**真实结构缺陷**；
- MOFDiff 的 2 个工具失败经 MACE 后仍无效（片段/重叠）；
- 因此 MOFFlow-2 的最终有效率从 32.5% 修正为 **66.2%**，排名由第三升到第二。

## 3. 观察

1. **没有引擎是“开箱干净”的**：原始结构 40–67% 存在原子重叠或断开片段。结构有效性核查/弛豫不是可选步骤。
2. **EGMOF**：最终有效率最高（80/89 = 89.9%），断开片段最少（4.5%），体积覆盖最宽；但原始重叠率最高（58.4%），说明 PORMAKE 组装的几何需要弛豫来修复。
3. **MOFFlow-2**：工具修正后最终有效率 **51/77 = 66.2%**（原 32.5%）；在 UFF 能处理的 26 个结构里只有 1 个无效（3.8%），说明其结构本身相当可靠。25 个工具失败结构经 MACE 后仍为多片段，属真实缺陷。缺点仍是化学式唯一率最低（70%）和体积范围最窄（923–4444 Å³）。
4. **MOFDiff**：最终有效率最低（41/79 = 51.9%）；UFF 能处理的 77 个里仍有 36 个无效（46.8%），是三家中最严重的**装配缺陷**（27.8% 断开片段）。优点是无重复、化学式 100% 唯一。
5. **条件有效性**（UFF 可处理的结构中）：MOFFlow-2 96.2%、EGMOF 89.9%、MOFDiff 53.2%。MOFDiff 的问题主要来自组装本身，而不是弛豫器。
6. **唯一性**：MOFDiff/EGMOF 本批次无重复；MOFFlow-2 有 8 个重复（化学式重复率 30%），多样性较低。

## 4. 方法学限制

- 每引擎仅 100 样本、单种子；比例的不确定度约 ±10%。
- “片段”判定基于共价半径，金属-有机配位键可能被漏判或误判；与 UFF 后的判定会有差异。
- 0.9 Å 阈值是硬阈值；部分 0.85–0.95 Å 的短接触可能是正常的强氢键/金属-配体距离，但不是共价键。
- UFF 可参数化率受 lammps-interface 版本和 CIF 格式影响；MOFFlow-2 的失败不能全部归因于结构。
- MACE fallback 使用 MACE-MP 势，不是 UFF；用于几何有效性判定（重叠/片段/体积），其能量和局部结构不能与 UFF 结果等价；MACE-MP 对 Cu/Zn/V 金属中心的可靠性未系统校验。
- Novelty 与构筑块新颖性已完成（§7）；BW-DB 仍缺，MOFDiff 的记忆化检查未做。

## 7. 结构 novelty 与构筑块新颖性（2026-11-11）

数据库已镜像到服务器 `/share/rickyswork/ai_mof/databases/`（清单见该目录 README）：CSD 15,906、CoRE 2024 20,276、hMOF 20,649、MOSAEC 309,179，合计 **365,010 个 CIF**。索引在 `databases/index/`（轻量解析：gcd 约化化学式 + 体积）。

### 7.1 结构级 novelty

**精确预筛**（同化学式是结构相同的必要条件）+ StructureMatcher：

| 引擎 | N | CSD 同式/匹配 | CoRE 2024 | hMOF | MOSAEC |
|---|---|---|---|---|---|
| MOFDiff | 79 | 0 / 0 | 2 / 0 | 2 / 0 | 2 / 0 |
| MOFFlow-2 | 77 | 0 / 0 | 3 / 0 | 2 / 0 | 1 / 0 |
| EGMOF | 89 | 0 / 0 | 8 / 0 | 16 / 0 | 13 / 0 |

**有效弛豫结构复核**（41/51/80 个）：0 结构匹配（同式候选数略降）。

**宽松匹配**（元素集合 + 体积比 0.5–2.0 + 每库取体积最近 400 个 + StructureMatcher）：CSD / CoRE 2024 / hMOF 仍 **0 匹配**（有界搜索，非穷尽；MOSAEC 只做了精确预筛）。

结论：三引擎生成的组装结构在 36.5 万参考结构中**没有精确结构重复**。EGMOF 的同化学式候选最多（CoRE 8、hMOF 16、MOSAEC 13），但都不是同一结构；这与其使用固定 BB 库、组合空间与假设库重叠较多一致。

### 7.2 构筑块新颖性

**EGMOF**（固定 BB 库，novelty 只在组合层面）：

- 89 个结构使用 **30 个拓扑**（pcu 25、fsc 14、qtz-x 7、tsx 4…）、**54 个 node BB**；
- 65 个唯一的 (拓扑, node BB 集合, edge BB 集合) 组合，其中 9 个组合重复（24 个结构共享组合）。

**MOFFlow-2**（字符级 SMILES 生成，相对 187,047 条训练序列 / 148,102 个有机 SBU）：

- 生成的有机 SBU：**83 个 RDKit 有效且唯一，其中 18 个（21.7%）不在训练集**；
- **17/100 条生成序列含至少 1 个新有机 SBU**；
- 金属节点：6 个唯一，1 个新；
- 序列：79/100 唯一，**69/100 不在训练集**；
- **25 个 SBU 字符串 RDKit 无法解析（23 个唯一）**——生成质量问题，约占 SBU 总数的 5%。

结论：MOFFlow-2 确实能产出训练集之外的有机构筑块（约 22% 的 SBU 词汇、17% 的样本），这是它与 EGMOF（只能重组合固定 BB）的本质区别；代价是约 5% 的化学无效输出。

### 7.3 限制

- **BW-DB 缺失**：MOFDiff 的训练集未镜像，无法检查 MOFDiff 的记忆化/训练集泄漏。
- 精确化学式预筛是必要不充分；宽松匹配每库只取体积最近 400 个，属有界搜索，不能排除更远的同构体。
- MOSAEC 只做了精确预筛；其 30 万结构未做宽松匹配。
- “新颖”= 不在参考库/训练集中，不等于可合成、热力学稳定或实验可达。
- RDKit canonicalization 可能把不同质子化/电荷状态视为不同 SBU；新 SBU 中也包含若干看起来可疑的片段，需要逐条化学审查。

### 7.5 新 SBU 化学审查（MOFFlow-2，18 个）

对 18 个训练集外、RDKit 有效的有机 SBU 逐条审查（羧酸根/芳香 N/硫醇/膦酸等结合基团、自由基、电荷、芳环、SAscore、与训练 SBU 的 Morgan 指纹最近邻）：

- **12/18 判为可行的 MOF 连接体**：≥2 个结合基团、无自由基、含芳环、电荷与阴离子数一致；其中 11 个含 ≥2 羧酸根，1 个为双吡唑类（4 个 N 给体），1 个为三羧酸（charge −3 正常）。
- 6 个不可行：2 个含卡宾/自由基（`[C]`）、2 个单羧酸（bind=1）、2 个非连接体（偶氮小分子 `CC/N=N/C`、亚硝酸类 `O[N-]O`）。
- SAscore 中位 3.62（2.59–6.76）；可行连接体集中在 2.98–4.00。
- **与训练 SBU 的最近邻 Tanimoto：14/18 ≥0.7，0/18 <0.4**——所有“新”SBU 都是已知 SBU 的近邻修饰/类似物，没有全新骨架。
- 结论：MOFFlow-2 的构筑块新颖性主要是**近邻类似物生成**（decoration/analog），而非骨架创新；约 2/3 的“新 BB”具备连接体基本条件，其余含自由基或根本不是连接体。

文件：`generation/novelty/mofflow2_novel_sbu_review.csv`；脚本 `generation/mofdiff_plausibility/review_novel_sbus.py`。

## 8. 生成输出化学后过滤（MOFFlow-2，2026-11-11）

**规则**（`generation/mofdiff_plausibility/filter_generated_sbus.py`）：

- 无机节点：含金属 → 跳过；非碳阴离子（`[O-2]`、`[OH-]`、卤素等白名单）→ 作为节点组分接受；
- 有机 SBU（含碳）：RDKit 可解析、无自由基、电荷 ≤0 为**硬有效**；再加 ≥2 个结合基团（羧酸/芳香 N/酚羟基/腈/胺/硫醇/膦酸/磺酸）为**连接体适用**；
- 非碳、非节点的游离小分子 → 记为 **guest**（单独统计，不混入配体缺陷）。

**校准**（训练集随机 20,000 条序列 vs 生成 100 条）：

| 指标 | 训练集 | MOFFlow-2 生成 |
|---|---|---|
| 有机 SBU 硬有效 | 88.3% | **81.0%** |
| 连接体适用 | 83.6% | **77.0%** |
| 无 guest | 61.5% | **55.0%** |
| 连接体适用且无 guest | 48.5% | **41.0%** |

生成质量各项约为训练分布的 85–93%，并非早期误分类时的 3–6%。

**口径说明（2026-11-12 复核）**：上表是 11-11 的校准记录，混用了 per-SBU 与 per-sequence。从逐序列 CSV（`generation/novelty/mofflow2_chemfilter_sequences.csv`）复核：生成集 **per-sequence** 硬有效 44.0%、连接体适用 41.0%、no-guest 55.0%；表中 77% 对应 **per-SBU** 连接体适用率（76.9%），81% 无法从该 CSV 复现（per-SBU 硬有效为 92.3%）。端到端的 18/100 用的正是 per-sequence 的 41%，与此一致。scale1000 复核（`generation/scale1000_mofflow2/chem_filter_1000.csv`）得到 per-sequence 47.2%/45.6%/57.6%、per-SBU 硬有效 83.5%/连接体适用 69.1%，与 pilot100 同口径、略有下降。

**端到端**（100 条序列 → 77 个组装 CIF → UFF/MACE 结构有效性）：

- 化学有效序列 **41/100**（已组装 40 个）；
- **化学有效 + 结构有效 = 18/100（18%）**；
- 生成序列的失败原因：guest 45、RDKit 无法解析 21、bind<2 6、自由基 3、电荷 1。

结论：MOFFlow-2 的化学质量接近其训练分布；过滤器的正确用法是丢弃化学无效序列、对 guest 单独处理，而不是把所有 guest 都算作配体缺陷。端到端可用率约 18%，这是目前 MOFFlow-2 结构化生成的真实产出率。

文件：`generation/novelty/mofflow2_chemfilter_sequences.csv`、`mofflow2_chemfilter_end2end.csv`；脚本 `filter_generated_sbus.py`。

### 9.1 结论

1. **结构有效率排序：EGMOF 87.7% > MOFDiff 59.0% ≈ MOFFlow-2 56.6%**。pilot100 的 MOFFlow-2 66.2% > MOFDiff 51.9% 在大样本下收敛；100 样本的排名受批次方差影响明显。
2. **MOFFlow-2 的取舍**：原始几何最干净（clean 40.6%、断片 11.9%），但化学端到端只有 16.6%，化学式唯一率仅 41.9%（BB 词汇有限、同式异构多）。它与 MOFDiff 结构有效率同档，但**分子多样性明显更差**。
3. **EGMOF**：最终有效率最高、断片最少（4.4%），但原始重叠最多（64.6%）、约 21% 输出重复；BB 固定，novelty 只在组合层面。
4. **MOFDiff**：结构与化学式几乎全唯一（99.6%），但装配缺陷最重（断片 24.2%、重叠 51.5%），最终有效率与 MOFFlow-2 同档。
5. **新颖性**：三引擎在 365,010 个参考结构中均 **0 结构重复**；MOFFlow-2 是唯一有真实新 SBU 的引擎（31% SBU、16.2% 样本），但仍以近邻类似物为主。MOFDiff/EGMOF 的 BB 均来自固定缓存/库。
6. **分母与保守性**：MACE 超时（18/62/5）记为 unresolved，不是结构判定失败；分母含超时项，因此 MOFDiff/MOFFlow-2 的最终有效率是**保守下限**。

### 9.2 限制

- 条件可控性尚未评价：MOFFlow-2/EGMOF 的目标值（CO₂ working capacity 5.0）没有用独立模型或 GCMC 验证生成结构的实际性质。
- MOFDiff 记忆化检查仍缺 BW-DB（Zenodo 对服务器 IP 限流超过 24 h）。
- 单批次、单种子；1000 样本的 ±1.5–2% 是统计口径，但引擎间差异（如 59% vs 88%）远超此范围。
- UFF 失败中的工具 bug 与结构缺陷已通过 MACE 分流，但 MACE-MP 对 Cu/Zn/V 的可靠性仍未系统校验。
