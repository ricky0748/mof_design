# 直线预筛专项核查（2026-11-13）

结论：连接方向是有用的几何描述；第一轮新增的20°轴向硬门槛没有通过本批次的有效性检验，应从硬拒绝条件改为记录指标。

## 判据来源与差别

support/anchor_rules.py:267的原有描述规则：两端连接方向彼此夹角≥160°时标记linear。compatible()只检查锚点化学类型与节点兼容，不执行20°轴向拒绝。

v1 build.py:41–53新增规则：分别计算每端(X−母原子)方向与外向X–X轴夹角，只要任一端>20°就直接返回incompatible，组装器尚未运行。

两者不等价。两条方向接近反平行时，仍可能同时偏离两端点的连线。v1协议“与现有锚点判据一致”的描述不准确。

## 逐样本核查

20个目标两端方向互相夹角为167.8747°–179.8057°，原有规则全部标记linear。旧轴向最大偏角13.5202°–34.4373°，20°门槛保留1个、30°保留8个、35°保留20个。

v1/v2有17个样本的构筑块XYZ SHA256完全相同，包括16个旧门槛拒绝者和1个通过者；它们在U组全部通过联合终点。其余3个涉及电荷归一化修正，单列。U组20个任务17–126步收敛；最短原子距离0.9256–1.0877 Å，体积比0.9895–1.0076，连通分量均为1，目标连接体恢复且拓扑pcu。

## 保留的验收与后续

取消发生在PORMAKE调用前的手工预拒绝层。实际构建、统一MACE弛豫、原子数/距离/连通性/体积验收和MOFid身份检查均保留。现有终点覆盖几何与身份，未直接评价配位角应变、能量相对稳定性或实验可合成性；20°轴向规则也没有建立与这些量的对应关系。

前一轮“成功因为构象弛豫调整”的解释只是可能机制，当前证据直接支持的是预筛判据错配；本次没有做逐步配位角轨迹分析。下一步在独立批次记录这些角度与最终失败的关系，再决定是否建立经过校准的计算预算筛选规则。
