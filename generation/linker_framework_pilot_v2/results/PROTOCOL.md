# 连接体—框架小试 v2：几何匹配与门槛消融

2026-11-13，使用v1冻结的同一批20个连接体，不重新挑选样本。

## 动机与更正

v1的19次拒绝发生在“连接方向相对X–X直线≤20°”的预筛，尚未实际构建这些候选。审计发现，EGMOF已通过几何筛查的框架含28–37°及更弯曲的参考连接体；这说明该线性边假设不是普遍适用的兼容性判据。v1结果保留，v2以消融分开检验预筛与模板选择。

另发现v1锚点模块的中和函数处理全部负氧，可能改变硝基等基团电荷。v2仅将`C(=O)[O-]`变为羧酸，保留其他原子电荷和重原子连接图；用同一新函数回算旧结构的连接体恢复率，几何与优化结果直接复用。v1唯一成功案例L14不含该类基团。

## 试验臂与预算

- A：v1原生V框架的相同MACE结果，复用，不新增原生计算。
- B1：v1固定pcu/N16、直线方向门槛结果，原记录保留。
- U：仍用pcu/N16构建，取消相对直线的预筛。其余连接体、seed=7、组装器和弛豫条件保持。
- M：按下述已观测有效参考模板的方向/长度选择一个组合，再构建。M若与U选择同节点、同拓扑且原子坐标相同，则记录为同一结构，不宣称模板变化收益。
- 每连接体U、M各最多一次正式构建尝试。嵌入失败、无匹配、构建失败或超限均保留在20分母中，不替换样本和模板。
- 最多40次新正式MACE；相同初始结构按原子序列、晶胞、坐标8位小数指纹去重，可复用一次计算，报告别名。另最多3个校准结构。
- MACE模型与v1完全相同：medium/float64、变胞BFGS150步、fmax0.2、maxstep0.05、600秒、1000原子、最多8并发且每GPU一个任务、线程2。

## 模板池与几何匹配

模板池来源为EGMOF千样本中几何有效的落盘结构。限一个节点类型、一个非E0连接体类型，拓扑只有一个节点类型且连接数匹配。节点所有连接点必须接到具有两个O邻居的羧基C；参考连接体两个X各只有一个C母原子。混合N给体/羧酸节点排除。

提取每个参考连接体的：两端“X−母原子”方向相对X–X向外轴的角度、两条出射方向之间夹角、X–X距离。目标连接体使用相同描述符；两端互换取较好匹配。

- 最大三角差≤20°；X–X长度比0.5–2.0。
- 排名：最大角差 + 10×|ln(长度比)|；同分按参考框架名字排序。
- 每个连接体只取排名第一的参考组合，锁定其拓扑与节点；参考边只用于匹配，不带入额外有机连接体。
- 保存所有候选分数、入排原因、模板及其源CIF和构筑块/拓扑文件哈希。几何匹配分数与结果评价分开，冻结后不按弛豫结果改选。

U/M连接体输入重原子图保持一致；仅羧酸质子化状态按统一规则标准化。模板更换可能改变节点、拓扑和化学计量，逐例报告这些变化。

## 校准与验收

线性阳性控制BDC/pcu/N16必须通过几何、连接体恢复、完整拓扑。另运行一个弯曲连接体校准（间苯二甲酸，按同规则匹配）与一个最常用匹配组合的原库构筑块重建控制，后两者按诊断结果报告。

校准后执行冻结20样本。主终点仍为几何有效 + MOFid恢复目标连接体 + 完整拓扑身份。其他终点、几何阈值、收敛单列与v1一致；MOFid未解析、运行错误、超时、模板未匹配分别记录。

比较：U−B1检验预筛门槛；M−U检验匹配策略（实际结构相同者单列）；U/M−A仅对应框架构建方案整体差异。所有比较为同一批历史样本上的后续诊断，收益需要独立新批次确认。报告8个训练序列外、12个训练内片段分层。
