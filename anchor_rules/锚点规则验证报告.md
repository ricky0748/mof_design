# 锚点规则验证报告（CoRE MOF 2024）

2026-10-19 · 数据：`MOF-公开数据库/core2024/CR_data_CSD_modified_20250227.csv` 中 9,835 个结构的 MOFid-v1

## 一句话结论

第一版规则（羧酸、唑类、吡啶）能完整识别 84.8% 结构的全部有机配体；按出现次数加权，配体覆盖率为 87.4%。拿 Nexerra 式的纯几何规则做对照：在 475 个纯羧酸配体上，它选出的锚点位置只有 42% 与真实羧基位置化学等价；即使只看两个锚点的配体，也有一半选错。错误高度系统化：把间位选成对位，把弯曲配体变成直线配体。

## 2. 纯几何规则 vs 化学规则

**方法**：在 CoRE 中只含羧基、羧基数 ≥ 2 的配体里随机抽 500 个，最后有效样本 475 个。先把羧基换成 H 得到"裸核"，再按 Nexerra 的做法，在所有 C–H 里选平均两两距离最大的 k 个（k 等于真实羧基数），然后比较几何规则选出的位点与真实羧基位点。判断两者一致时考虑分子对称性：在选中的 C 上挂哑原子，比较规范 SMILES 是否相同。

| 指标 | 数值 |
|---|---|
| 化学等价一致率（考虑对称性） | 41.9% |
| 按出现次数加权的一致率 | 65.4%（常见配体 BDC、BPDC 都能选对，所以加权后偏高） |
| 平均位点重合率 | 59.1% |

**按锚点数 k 拆开：**

| k | 样本数 | 一致率 |
|---|---|---|
| 2 | 233 | 48.1% |
| 3 | 95 | 57.9% |
| 4 | 126 | 23.0% |
| 5 | 4 | 25.0% |
| 6 | 15 | 13.3% |
| 8 | 2 | 0% |

**典型错误（k = 2，按出现次数排序）：**

| 真实配体 | 几何规则给出的 | 出现次数 | 后果 |
|---|---|---|---|
| 间苯二甲酸 `*c1cccc(*)c1` | 对苯二甲酸 `*c1ccc(*)cc1` | 123 | 120° 弯曲变成 180° 直线，拓扑完全不同 |
| 1,4-萘二甲酸 | 2,6-萘二甲酸 | 44 | 构型改变 |
| 5-氨基间苯二甲酸 | 2-氨基对苯二甲酸 | 43 | 拓扑改变，氨基从孔口位置移到别处 |
| 5-硝基 / 5-磺酸基 / 5-羟基间苯二甲酸 | 对应的取代对苯二甲酸 | 39 / 37 / 22 | 同上 |
| 9,10-蒽二甲酸 | 2,6-蒽二甲酸 | 11 | 构型改变 |
| 邻苯二甲酸 | 对苯二甲酸 | 12 | 螯合配体变成直线桥连配体 |

规律很清楚：几何规则天然偏向"最长、最直"的位点组合，所以弯曲配体、带取代基的配体，以及锚点数 ≥ 4 的配体，几乎都会被改写。另外，它根本无法表达 N 给体，唑类和吡啶类配体不在可比范围内，上面这些数字还没算上它们。

**对项目的含义**：启动文档里"锚点必须自己写"的判断，现在有了定量依据。直接用 Nexerra 的锚点逻辑，生成配体的连接方式有一半以上是错的；而且错的不是噪声，是系统性地把配体推向直线型，候选的拓扑多样性会被压缩。

## 3. 节点条件化的必要性（示例）

| 配体 | 不指定节点 | 指定 Al 棒节点 |
|---|---|---|
| PZDC（MOF-303） | 羧酸 + 吡唑，4 个连接点 | 只有 2 个羧基配位，吡唑 NH 记为孔道基团 |
| 异烟酸 | 羧酸 + 吡啶，2 个连接点 | 只剩羧基，1 个连接点，不可用 |
| 2,6-吡啶二甲酸 | 羧酸（吡啶 N 螯合，记为可选给体） | 同左 |

同一个配体放到不同节点上，配位方式和孔道化学都不一样。因此锚点指定必须以"配体 + 目标节点"作为输入。

## 4. 局限

- 验证用的是 MOFid 字符串里已有的配体，属于识别覆盖率测试。组装层面的测试见 `组装测试报告.md`（PORMAKE）。
- 吡啶 N"是否配位"目前只用邻位螯合这一条规则判断；吡嗪、嘧啶 N 一律算作给体，实际可能偏多。指定节点之后影响会小一些。
- 四唑、1,2,3-三唑的默认给体选择（N2/N3、N1/N3）只覆盖最常见的一种配位方式。
- 组装器已选定 PORMAKE，默认导出 PORMAKE xyz（X 在被切断键中点）；ToBaCCo CIF 导出保留，但未与实际 ToBaCCo 代码核对。
