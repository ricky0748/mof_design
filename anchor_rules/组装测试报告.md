# 锚点规则 → PORMAKE 组装测试

2026-10-19 · 脚本 `assembly_test.py` · 结果 `assembly_out/`

## 一句话结论

PORMAKE 对任何输入都能"建出"结构，所以"构建成功"不能当判据。按几何判据（连接方向、碰撞、成键长度、局部结构 RMSD）算，化学锚点在 CoRE 纯羧酸配体上的组装成功率只有 20–30%。失败的主因是配体形状（弯曲或柔性）与拓扑不匹配，不是锚点本身有问题：连接方向合格的配体放进 pcu，成功率是 92%。几何锚点的表观成功率更高（pcu 50%），但它的成功里有将近一半配体已经被改写成了别的分子。按"组装成功且化学正确"计，化学锚点在 pcu、tbo 上领先，nbo 上基本持平，fcu 上略低（20.8% 对 22.8%）。

## 设置

| 项 | 内容 |
|---|---|
| 配体 | CoRE MOF 2024 中的纯羧酸配体（无其他给体，≤ 60 个重原子）：二齿 149 个、三齿 80 个，随机抽样。两套锚点都能生成构筑块的配体才计入，所以两套是在同一批配体上配对比较 |
| 拓扑 / 节点 | 二齿配体作边：pcu + Zn4O（N16）、fcu + Zr6（N419）、nbo + Cu 桨轮（N17）。三齿配体作 3-c 节点：tbo + Cu 桨轮 |
| 化学锚点 | 本模块：羧基 C 归节点，X 放在 C(芳)–C(羧) 键的中点（PORMAKE 约定，组装时两侧 X 重合） |
| 几何锚点 | Nexerra 式：先把羧基换成 H，再在所有 C–H 中选平均两两距离最大的 k 个，X 放在 C 沿 C→H 方向 0.74 Å 处 |
| 构象 | 每个配体只取一个 ETKDG + MMFF 构象 |

成功判据（全部满足才算成功）：

| 判据 | 内容 |
|---|---|
| 连接方向 | 每个 X 的方向（母原子 → X）与理想方向的夹角 ≤ 20°。二齿配体的理想方向是 X–X 轴，三齿配体是 X 质心 → X |
| 局部结构 | 三齿配体与拓扑 3-c 局部结构的 PORMAKE Locator RMSD ≤ 0.3 |
| 碰撞 | 周期性边界下，非键原子对（已排除 1-2、1-3 关系）的距离：重原子之间 ≥ 1.5 Å，涉及 H ≥ 1.0 Å |
| 成键 | 有机部分的键长在 0.85–1.9 Å 之间 |

## 结果

各项是满足该判据的比例：

| 拓扑 / 锚点 | 构建 | 方向合格 | 无碰撞 | **成功** | 化学正确 | **成功且正确** |
|---|---|---|---|---|---|---|
| pcu / 化学 | 100% | 33% | 71% | 30.2% | 100% | **30.2%** |
| pcu / 几何 | 100% | 51% | 97% | 50.3% | 48% | 26.8% |
| fcu / 化学 | 100% | 33% | 34% | 20.8% | 100% | **20.8%** |
| fcu / 几何 | 100% | 51% | 73% | 39.6% | 48% | 22.8% |
| nbo / 化学 | 100% | 33% | 56% | 26.8% | 100% | **26.8%** |
| nbo / 几何 | 100% | 51% | 90% | 45.6% | 48% | 25.5% |
| tbo / 化学 | 100% | 38% | 64% | 20.0% | 100% | **20.0%** |
| tbo / 几何 | 100% | 39% | 81% | 25.0% | 51% | 16.2% |

tbo 的 Locator RMSD 合格率：化学锚点 76%，几何锚点 68%。

**1. 构建永远"成功"。** PORMAKE 会把边构筑块的 X–X 轴硬对齐到拓扑边上，不检查连接方向，所以弯曲配体也能建出结构，只是建出来的连接是歪的。下游如果只看"能不能出 CIF"，弯曲配体会大量混进候选集。几何判据必须加。

**2. 化学锚点失败，主要是形状问题。** 只看连接方向合格的配体，成功率如下：

| 拓扑 | 化学锚点 | 几何锚点 |
|---|---|---|
| pcu | 92% | 99% |
| nbo | 82% | 90% |
| fcu | 63% | 78% |
| tbo | 53% | 65% |

不合格的那 67% 里有两类：

- **刚性弯曲配体**：例如间苯二甲酸系，固有偏角约 30°。它们本来就不属于 pcu、fcu 这类线性边拓扑。
- **柔性配体**：单一构象下偏角很大。可转动键 ≥ 4（含两个羧基）的配体中，大多数偏角超过 20°。

不同拓扑对方向合格的配体容忍度也不同：fcu 最密，碰撞最多；tbo 的问题在于两类节点的尺寸比是拓扑固定的，三齿配体的尺寸和 Cu 桨轮对不上时，构筑块之间的键会被拉长（键长中位数 2.16 Å），72% 因此不合格。

**3. 几何锚点的"成功"有一半是假的。** 以 pcu 为例：几何锚点成功了 75 个，其中 35 个化学上是错的。典型例子是 5-溴间苯二甲酸、5-氨基间苯二甲酸被改写成对位连接，于是"适配"了线性边。这类结构能建出来，但对应的配体并不是输入的那个分子。在 pcu 上只有几何锚点成功的 34 个配体里，31 个属于这种情况。几何锚点的高成功率正是来自"把弯曲配体拉直"，这与 `锚点规则验证报告.md` 的结论一致，这次在组装层面得到了印证。

**4. 方向偏差可以当作组装前的筛子。** 判据很便宜，只需配体的 3D 构象，不用组装。二齿配体方向合格时，放进 pcu 92% 能成功。所以流程上可以先算方向偏差，再按形状把配体分发到相应拓扑：线性的进 pcu/fcu/nbo，约 120° 弯曲的进 kgm/sql 等。这样就不必建了再筛。

## 对项目的含义

- 组装环节建议定为"锚点 → 形状分类 → 拓扑分发 → PORMAKE 组装 → 几何判据"。几何判据要写进命中率的分母：PORMAKE 建出来但判据不合格的结构，不能算有效候选。
- 生成端如果固定拓扑（受约束逆设计），可以把方向偏差作为生成时的约束或奖励，例如线性边要求偏差 ≤ 20°。

## 局限与下一步

- 每个配体只取了一个构象。柔性配体应在多构象中挑偏差最小的，这样化学锚点的方向合格率会明显上升。这是下一步最便宜的改进。
- 碰撞和成键阈值是经验值，没有做弛豫；PORMAKE 的输出建议再用 MLIP 或 UFF 快速弛豫一次，再判断是否合理。
- PORMAKE 库里没有 sql，弯曲配体的拓扑（kgm 等）这次没测。
- 只测了纯羧酸配体。唑类、吡啶配体需要对应的节点构筑块（ZIF 的 Zn 四面体、柱撑配体等），还要核对 PORMAKE 节点的 X 约定。
